## Overview

A personal portfolio presenting my projects, capabilities, experience and contact information through a desktop-style interface. Vue manages the interface and Three.js renders the surrounding 3D scene.

## Highlights

- Interactive power-on sequence and computer-inspired navigation.
- Project, experience and contact sections.
- Three.js scene with CSS3D-rendered interface content.
- Bundled résumé and personal imagery.

## Run locally

```bash
git clone https://github.com/Vaibhavpandey-web/Vaibhav-pandey-portfolio.git
cd Vaibhav-pandey-portfolio
python -m http.server 8080
```

Open [localhost:8080](http://localhost:8080). External libraries and assets require an internet connection.

## Deployment

Deploy the repository root as a static website with `index.html` as the entry point. No npm build step is required.

## Viewing notes

A WebGL-capable browser is needed for the 3D scene. The current interface is designed around a landscape desktop experience and includes a rotate-device prompt.
